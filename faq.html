FAQ

Clear answers before you change a price.

CostHarbor Supplier Updates for WooCommerce is intentionally cautious. These answers describe current version 0.1.3.

Does it automatically change prices?

No. Uploading and mapping a CSV does not change products. You must generate a preview, review the proposed changes, and explicitly apply them.

Does it support variations?

Yes. It uses WooCommerce's public SKU lookup, which supports simple product SKUs and variation SKUs.

How do I prepare my first CSV?

Open the CostHarbor screen and download the catalog template. It includes your current product and variation SKUs; enter Supplier Cost values, save it as CSV, upload it, and review the mandatory Preview. A blank template is also available.

Does it send store data anywhere?

No. Current version 0.1.3 makes no external requests and sends no CSV content, store data, telemetry, or analytics to an outside service.

Can I undo an import?

Yes. The latest applied import can be rolled back. Rollback restores only the supplier cost and regular price changed by that import.

What happens if an SKU is missing?

The row is marked not found, blocked, and skipped. CostHarbor Supplier Updates for WooCommerce does not create a new product.

Does it work without WooCommerce COGS enabled?

Yes. CostHarbor Supplier Updates for WooCommerce keeps its own supplier cost as the durable source of truth. Native COGS is synchronized only when WooCommerce exposes its supported public methods.

What happens with duplicate SKUs?

Duplicate or ambiguous rows are blocked so the plugin does not guess which update should win.

Does it change sale prices or stock?

No. The current import workflow updates CostHarbor Supplier Updates for WooCommerce's cost and, when approved, the WooCommerce regular price. It does not update sale prices, stock, titles, or categories.
