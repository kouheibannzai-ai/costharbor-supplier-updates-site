Requirements

  • WordPress 6.5 or later
  • PHP 7.4 or later
  • WooCommerce installed and active
  • An administrator account with the manage_woocommerce capability

Installation

  1. Install and activate WooCommerce.
  2. In WordPress, open Plugins → Add New.
  3. Search for CostHarbor Supplier Updates for WooCommerce, then install and activate it.
  4. Open WooCommerce → CostHarbor Supplier Updates for WooCommerce.
Install CostHarbor Supplier Updates from the official WordPress.org directory.

Preparing a CSV

Use one header row followed by up to 10,000 data rows. The maximum file size is 10 MB. UTF-8 is recommended. Comma, semicolon, tab, and pipe delimiters are detected.

ColumnRequiredPurpose
SKUYesMatches an existing simple product or variation.
Supplier CostYesNew positive numeric supplier cost.
Supplier SKUNoReference information from the supplier.
Product NameNoHuman-readable reference during review.

Do not include currency symbols, formulas, scientific notation, or comma-decimal values. CostHarbor Supplier Updates for WooCommerce never creates a product for an unknown SKU.

Column mapping

After upload, select which CSV columns contain SKU and Supplier Cost. Optionally map Supplier SKU and Product Name. Check the selected labels before proceeding; a mapping does not update products.

Markup vs Target Margin

Both methods calculate a proposed regular price from the new supplier cost:

MethodFormulaCost 100 at 50%
Markupcost × (1 + percentage)150
Target Margincost ÷ (1 − percentage)200

Target margin must be below 100%. The percentage and warning threshold are validated before preview.

Preview warnings

The preview is mandatory. By default, a proposed regular-price movement of 50% or more is a warning. You may configure this threshold.

Blocked rows

  • SKU not found
  • Duplicate or ambiguous SKU
  • Missing, invalid, non-numeric, or non-positive cost
  • Non-positive proposed price

Warning rows

Large proposed price movements are highlighted for deliberate review. Blocked rows cannot be applied.

Before applying: check the proposed price, formula choice, percentage, warning rows, and currency context. CostHarbor Supplier Updates for WooCommerce does not perform currency conversion.

Applying updates

After preview, an authorized administrator may choose Apply safe rows. A nonce and server-side preview token protect the operation. The result shows total, matched, changed, skipped, warning, and failed counts, so partial failures remain visible.

Rollback

The latest applied import can be rolled back from Import History. Rollback restores:

  • The CostHarbor Supplier Updates for WooCommerce supplier cost changed by that import
  • The WooCommerce regular price changed by that import

It does not change titles, stock, sale prices, categories, or unrelated metadata. Review the result after rollback because a product may have been edited separately since the import.

Import History

History records the execution time, CSV filename, row totals, match and change counts, skipped and warning rows, failures, and rollback status. The current version retains the 20 most recent imports to bound stored data.

Native WooCommerce COGS behavior

CostHarbor Supplier Updates for WooCommerce keeps its own supplier cost as the durable source of truth. When the installed WooCommerce version exposes its public Cost of Goods methods, the plugin also synchronizes through those methods. It does not access private WooCommerce COGS metadata.

The workflow still works when native WooCommerce COGS is unavailable or disabled; the plugin's own supplier cost remains stored.

Uninstall and data retention

By default, uninstall preserves supplier costs and import history as business data while temporary data is removed. Administrators can explicitly enable permanent deletion before uninstalling. That choice is irreversible and is clearly labeled in the interface.
