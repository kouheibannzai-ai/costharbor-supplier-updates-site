Privacy

Your supplier data stays in your store.

This page describes CostHarbor Supplier Updates for WooCommerce version 0.1.2 and this static documentation website.

SummaryPluginWebsiteStored dataFuture changes

Current plugin behavior

CostHarbor Supplier Updates for WooCommerce version 0.1.2 processes uploaded CSV content inside the WordPress and WooCommerce installation where the plugin runs.

  • No external server communication
  • No telemetry
  • No analytics
  • No tracking
  • No advertising network
  • No transmission of CSV content or store data

This website

This is a static documentation and product information site. It does not use analytics, cookies, advertising, email collection, user accounts, or external APIs.

Data stored by the plugin

The plugin stores supplier cost metadata, bounded import history, and rollback snapshots in the store's WordPress database. The current version retains the 20 most recent imports. Temporary import data is removed when no longer required.

By default, uninstall preserves supplier costs and import history as business data. An administrator can opt into permanent deletion before uninstalling.

Future versions

This statement applies to the current version identified above. If a future version changes its data handling, the relevant plugin documentation and this page should be updated before that version is released.
